# UI.md

## 1. 风格

参考方向：

- Notion
- Obsidian
- Linear
- 现代教育平台

关键词：

- 简洁
- 专业
- 高信息密度
- 长时间阅读友好
- 暗色模式
- 少动画

避免：

- 大面积渐变
- 无意义 3D
- 过度玻璃拟态
- 巨型按钮
- 过度游戏化

## 2. 首页

展示：

- 全局搜索
- 最近学习
- 课程分类
- 今日待复习
- 学习进度
- 高频复试入口

## 3. 教材页

树形目录：

```text
第一章
 ├─ 1.1
 ├─ 1.2
 └─ 1.3
```

支持折叠。

## 4. 知识点页

桌面端三栏：

```text
左：教材/知识目录
中：正文
右：复试助手
```

中间正文建议顺序：

1. 一句话定义
2. 标准定义
3. 通俗理解
4. 原理
5. 公式
6. 物理意义
7. 工程意义
8. 例子
9. 易错点
10. 关联知识

右侧：

- 重要程度
- 问答重要度
- 收藏
- 学习状态
- 复试问题
- 追问链
- 问 AI

## 5. 移动端

- AppShell 在窄屏显示底部导航，可返回首页、进入课程、搜索和收藏。
- 知识点页在窄屏显示顶部上下文导航，可返回首页、课程、教材和搜索。
- 教材目录在窄屏收起为内容区域中的可滚动目录，不要求保持桌面三栏布局。

改成单栏：

正文优先。

目录、复试助手通过抽屉或 Tab 打开。
