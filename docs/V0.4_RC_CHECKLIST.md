## KnowledgePoint learning content

- `commonMistakes` and `masteryCriteria` remain nullable and backward compatible.
- Common questions and concise, standard and deep answers remain reusable.
- Knowledge Bundle schemaVersion remains `1.0`; optional learning fields and questions remain compatible with old v1 bundles.
- Search and admin content management remain covered by existing verification.

## Quick Learning

- Priority remains `REVIEW > LEARNING > NOT_STARTED > MASTERED`.
- Course scope is retained only when it matches the current KnowledgePoint course.
- Excluding the current point, single-candidate retry and random offset remain deterministic safeguards.
- Selection is read-only and does not write `StudyProgress`, `ReviewRecord` or `PracticeAttempt`.

## Mobile regression

- Learning information and actions remain reachable before long-form content.
- Mobile textbook context reuses `ChapterTree` and preserves the current point.
- Narrow-screen Q&A wrapping and previous/next navigation remain usable.
- Real 360/390/412 viewport inspection: **Not tested in this environment**.
