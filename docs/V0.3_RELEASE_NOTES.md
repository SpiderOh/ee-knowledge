# EE Knowledge v0.3.0

## Release scope

v0.3.0 Mobile & Personal Cloud 正式完成，包含：

- PWA 与 Android install foundation、移动端 UX
- single-user Authentication、private-by-default 页面和 API、HttpOnly signed session
- Native Node + systemd Linux self-host 与 Caddy HTTPS architecture
- 127.0.0.1-only Next.js、production environment validation 和 server-side SQLite canonical data source
- cold backup、live SQLite backup、daily scheduled backup、Primary retention 和可选独立 Secondary
- same-filesystem fail-closed、Secondary SHA-256 与 SQLite `integrity_check`
- production runtime HTTP integration verification 和 GitHub Actions CI

## Verification

`release:check` 覆盖 PWA、Authentication、deployment、backup、MVP、typecheck、lint、build 和 runtime verification。仓库 CI 使用 Node 20、系统 `sqlite3`、migration、只读 `db:check` 与同一 release gate。

v0.3.0 未新增新的 Prisma schema change；v0.3 阶段没有新增 migration。Knowledge Bundle v1 保持不变。

## Upgrade from v0.2.0

已有自托管服务请先停止服务并创建 cold backup，再更新代码：

```bash
sudo systemctl stop ee-knowledge
npm run db:backup
git pull --ff-only
npm ci
npm run build
npm run db
npm run db:check
sudo systemctl start ee-knowledge
```

首次进入 v0.3 self-host 时，还需按 [`docs/SELF_HOST.md`](SELF_HOST.md) 配置 Auth、systemd 和 Caddy；认证配置见 [`docs/AUTH.md`](AUTH.md)，完整备份与恢复见 [`docs/BACKUP_RESTORE.md`](BACKUP_RESTORE.md)。

## Target environment limits

仓库自动化不替代目标环境验收。真实 Orange Pi / NAS / Android / public HTTPS 需要在目标环境执行；这些场景未由本轮仓库自动化实际测试，记录为 `Not tested by repository automation`。

## Not included

- offline-first edits
- 手机独立 SQLite 或双向同步
- Capacitor / native APK
- multi-user / RBAC
- PostgreSQL
- AI
- 独立复试系统
- v0.4 Knowledge Learning Polish 功能

## Safety boundary

本版本保持 single-user personal system、private-by-default 和 server DB canonical data source；备份不会自动 restore，个人数据库不在本轮发布验证中被 seed、restore 或删除。

下一阶段：v0.4.0 Knowledge Learning Polish。AI 不属于 v1.0 主路线，独立复试系统也不属于 v1.0 主路线。
