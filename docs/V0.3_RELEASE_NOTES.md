# EE Knowledge v0.3.0-rc.1

## Candidate scope

v0.3.0-rc.1 将 EE Knowledge 的 single-user 个人系统部署到可验证的移动端和个人云基础：PWA 安装元数据、Authentication、Linux self-host、Caddy HTTPS reverse proxy、server-side SQLite、scheduled backup 和可选独立 Secondary backup destination。

本候选还增加了生产构建后的隔离运行时回归。它会使用临时 SQLite 验证公开 PWA 资源、私有页面、认证 API、登录、认证页面/API、unsafe `next` 防护和退出登录，不会操作真实用户数据库。

## Verification

`release:check` 依次覆盖 PWA、Authentication、deployment、backup、MVP、typecheck、lint、build 和 runtime verification。GitHub Actions 使用 Node 20 和系统 `sqlite3` CLI 重复 migration、只读完整性检查及 release gate。

## Not included

本候选不包含 offline-first edits、双向 SQLite synchronization、multi-user、RBAC、PostgreSQL、Capacitor APK、Local AI、RAG、知识图谱、复试题库或云厂商服务。

真实 Orange Pi/NAS、systemd timer、Caddy 公网 HTTPS、Android 安装和 USB/NAS 掉线恢复仍需要在目标环境执行人工 smoke test。

## Next

RC 审查并合并后发布 `v0.3.0` stable；之后再评估 v0.4.0 的学习体验增强。
