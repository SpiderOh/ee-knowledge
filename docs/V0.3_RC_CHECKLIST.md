# v0.3.0-rc.1 Release Checklist

## Scope

本候选版本覆盖 PWA、single-user Authentication、Linux self-host、HTTPS reverse proxy、server-side SQLite、scheduled/secondary backup，以及生产构建后的隔离运行时回归。Schema、migration、Knowledge Bundle 和依赖图保持不变。

## Automated gate

```bash
npm ci
npm run db
npm run db:check
npm run verify:pwa
npm run verify:auth
npm run verify:deploy
npm run verify:backup
npm run verify:mvp
npm run typecheck
npm run lint
npm run build
npm run verify:runtime
npm run release:check
```

`verify:runtime` 使用临时 SQLite 数据库和临时认证配置，不读取或修改个人数据库；它要求先完成 `.next` 生产构建。

## Target environment smoke test

- [ ] Orange Pi/RK3588 或 x86_64 Linux 上完成 `npm ci`、`build`、systemd 启动和 `db:check`
- [ ] Caddy 公网 HTTPS、登录、退出和移动端访问
- [ ] Android Chrome 安装 PWA，standalone 启动后访问同一服务器数据库
- [ ] Primary scheduled backup、Secondary 独立 filesystem、保留策略和掉线失败行为
- [ ] 真实 USB/NAS、systemd timer、HTTPS 和 Android 验收记录

当前仓库没有这些目标设备和公网环境，因此它们在本机报告为 Not tested。

## Release boundary

合并前不创建 tag 或 GitHub Release。RC 通过后，下一步才是合并到 `main` 并发布 `v0.3.0`。
